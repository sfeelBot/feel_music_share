# 화면별 스크린샷

> 이 폴더는 앱의 실제 화면 스크린샷을 모아두는 곳이다. QA 라운드마다 임시로 찍는 검증용 캡처(`docs/qa/`에 텍스트로 기록되고 원본 이미지는 보통 저장 안 함)와 달리, 여기 있는 파일들은 **"지금 앱이 실제로 어떻게 생겼는지"를 나중에 다시 볼 수 있도록 의도적으로 보존하는 것**이 목적이다.

## 파일명 규칙

`{화면번호}_{화면이름}.png` — 화면 번호는 `docs/design/00-ux-flow.md`의 번호 체계(2.1~2.14)를 따른다. 예: `2.5_home.png`, `2.10a_now-playing-spotify.png`.

## 최신성 안내

스크린샷은 캡처 시점의 스냅샷이다 — 이후 UI가 바뀌면 낡은 이미지가 된다. 큰 UI 변경(예: UI 폴리시 라운드) 이후에는 리더가 관련 화면만 다시 캡처해 교체하는 것을 권장한다. 각 이미지 파일의 git 커밋 이력(`git log -- docs/screenshots/`)이 곧 "언제 이 모습이었는지"의 기록이 된다.
