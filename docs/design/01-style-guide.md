# 01. 스타일 가이드 (초안 — 제안 단계)

> 상태: 초안(v1) — 2026-07-23 / **(2026-07-23 갱신)** YouTube MVP 승격에 따라 YouTube 브랜드 컬러 사용 원칙 추가
> 작성: 디자인 서브에이전트
> 주의: 아래 색상 값(HEX)·폰트는 **디자인 방향을 구체적으로 논의하기 위한 제안**이며 최종 확정이 아니다. 실제 브랜드 컬러/폰트 라이선스는 사용자(및 향후 브랜딩 논의)에서 확정한다.

## 1. 정서적 톤 (Tone & Manner)

앱의 정서적 핵심은 "**물리적 거리는 있지만, 지금 이 순간만큼은 함께**"다. 화면 전반에서 다음을 지향한다.

- **따뜻함(Warm)**: 차갑고 기술적인 "동기화 툴" 느낌이 아니라, 두 사람 혹은 여러 사람의 친밀한 순간을 담는 느낌.
- **신뢰(Trust/투명성)**: 재생 동기화라는 기술적으로 복잡한 일을 하고 있지만, 사용자에게는 항상 "지금 상태가 어떤지"를 숨기지 않고 보여준다 (US-406, 404와 직결). 불투명한 로딩보다 "무슨 일이 일어나고 있는지 설명하는" 태도.
- **가벼움(Light-weight)**: 방을 만들고 초대하고 함께 듣기까지의 과정에 마찰이 적어야 한다. 화려한 그래픽보다 빠르고 명료한 흐름 우선.
- **함께 만든다는 느낌(Collaborative)**: 플레이리스트가 "내 것"이 아니라 "우리가 같이 채워가는 것"이라는 느낌을 선곡자 배지, 참여자 아바타 등으로 계속 상기시킨다.

톤 안티패턴(피할 것):
- 지나치게 유치하거나 하트/이모지 남발로 가벼워 보이는 것 (친밀함과 유치함은 다르다).
- 기술적 상태(동기화 오차, 지연 ms 등)를 개발자 도구처럼 노출하는 것 — 사용자向 언어로 번역해서 보여줄 것.

## 2. 컬러 (제안, 미확정)

낮과 밤 상관없이 "따로 있지만 같은 순간을 공유"하는 느낌을 위해 **노을/황혼(dusk)** 팔레트를 기본 제안한다 — 하루 중 서로 다른 시간대에 있어도 같은 하늘 아래 있다는 은유.

| 용도 | 이름 | HEX (제안) | 비고 |
|---|---|---|---|
| Primary | Dusk Coral | `#FF6F61` | CTA 버튼, 강조 아이콘, 선곡자 배지 포인트 |
| Primary Dark | Deep Plum | `#4A2545` | 다크 배경, 헤더 |
| Secondary | Warm Amber | `#FFB25B` | 보조 강조, "재생 중" 표시 |
| Background (Light) | Soft Cream | `#FFF8F2` | 라이트 모드 배경 |
| Background (Dark) | Midnight Indigo | `#1E1730` | 다크 모드 배경 (음악 앱 특성상 다크 모드 우선순위 높음 제안) |
| Success / 동기화됨 | Sync Green | `#3FB68B` | 동기화 상태 정상 |
| Warning / 지연 | Amber Alert | `#F2A93B` | 동기화 지연 |
| Error / 끊김 | Muted Red | `#E4573D` | 연결 끊김, 오류 |
| Text Primary | Charcoal Plum | `#2B1E2E` | 라이트 모드 본문 |
| Text on Dark | Cream White | `#FBF3EC` | 다크 모드 본문 |

- Spotify 연동 화면 근처에서는 Spotify 공식 브랜드 가이드(초록 `#1DB954` 등)를 준용하되, 우리 앱 자체의 아이덴티티 컬러와 섞이지 않도록 "Spotify 관련 UI 요소"에 한정해서만 Spotify 그린을 사용하는 것을 제안(브랜드 혼동 방지 + Spotify 브랜드 가이드라인 준수 차원 — 실제 가이드라인 세부 조건은 배포 전 재확인 필요).
- **(2026-07-23 신규) YouTube 관련 UI 요소도 같은 원칙을 적용한다**: YouTube 공식 브랜드 레드(`#FF0000` 계열)는 Spotify 그린과 동일하게 "YouTube임을 명확히 표시해야 하는 지점"에만 한정해서 쓰는 것을 제안한다 — 예: YouTube 로고/워드마크가 노출되는 온보딩·로그인 화면(2.6b), 세션 생성 시 YouTube 라디오 선택 아이콘, 세션 설정의 "음악 서비스: YouTube" 표시 아이콘. 우리 앱 자체의 아이덴티티 컬러(Dusk Coral 등)나 동기화 상태 배지 색상 체계와는 절대 혼용하지 않는다 — 특히 동기화 상태의 "지연"(Amber Alert)·"끊김"(Muted Red) 색과 YouTube 브랜드 레드가 유사한 색역이라 혼동 소지가 있으므로, 동기화 상태 배지에는 어떤 경우에도 YouTube 브랜드 컬러를 쓰지 않는다(YouTube 로고/버튼 등 명시적 브랜드 표시 요소에만 한정). 실제 가이드라인 세부 조건(로고 사용 규정 등)은 배포 전 YouTube 브랜드 리소스 재확인이 필요하다.
- 다크모드를 1급 시민으로 취급하는 것을 제안한다: 음악 감상은 야간·조명 낮은 환경에서 많이 일어나고, 장거리 연인이 각자 다른 시간대(밤/낮)에 있을 수 있다는 서비스 특성과도 맞다.

## 3. 타이포그래피 (제안)

- **주 서체**: 시스템 기본 서체 우선 제안 (iOS: SF Pro, Android: Roboto 계열) — 크로스플랫폼 개발 초기 단계에서 커스텀 폰트 라이선스/번들 크기 부담을 줄이기 위함. 브랜드가 성숙한 이후 커스텀 서체 도입을 재검토.
- **한글 지원**: 시스템 기본 한글 서체(Apple SD Gothic Neo / Noto Sans KR 계열) 호환성 확인 필요.
- 위계(예시, 실제 포인트 값은 프레임워크 확정 후 조정):

| 레벨 | 용도 | 두께 | 크기(제안) |
|---|---|---|---|
| Display | 온보딩 카피, 세션 이름(대) | Bold | 28–32 |
| Title | 화면 제목, 곡 제목(Now Playing) | Semibold | 20–22 |
| Body | 본문, 아티스트명, 리스트 항목 | Regular/Medium | 15–16 |
| Caption | 선곡자 배지, 타임스탬프, 보조 정보 | Medium | 12–13 |
| Status | 동기화 상태 배지 전용 | Semibold | 12–13, 자간 살짝 넓게(가독성/강조) |

## 4. 컴포넌트 톤

- **버튼**: 모서리 둥근 pill 또는 큰 라운드(radius 큼) — 친밀하고 부드러운 인상. 1차 CTA는 Dusk Coral 채움, 2차는 outline.
- **아바타/프로필**: 원형, 선곡자 배지에 사용되는 아바타는 항상 작은 컬러 링(참여자별 고유 색)으로 테두리를 둘러 "누구 것인지" 색으로도 구분 가능하게 한다(색맹 접근성 고려해 색 단독이 아니라 이니셜/아이콘과 병행).
- **카드(플레이리스트 항목)**: 은은한 그림자 또는 배경색 대비만으로 구분(하드 보더 지양) — 딱딱하지 않게.
- **상태 배지(동기화)**: 텍스트 + 점(dot) 아이콘 조합. 애니메이션은 과하지 않게 — 예: "동기화 중"일 때만 점이 부드럽게 펄스, "동기화됨"은 정적.
- **모션**: 전반적으로 은은하고 부드러운 easing(급격한 바운스 지양). 단, 곡 추가/선곡 순간처럼 "누군가의 기여"를 알리는 지점에서는 짧고 경쾌한 마이크로 애니메이션으로 긍정적 피드백을 준다(예: 새로 추가된 곡 항목이 살짝 밝게 나타났다 정착).

## 5. 접근성 메모

- 동기화 상태(정상/지연/끊김)를 색상에만 의존하지 않고 아이콘 모양 + 텍스트 라벨을 항상 병행한다(색맹 사용자 고려).
- 선곡자 구분도 색 링 + 아바타 이미지/이니셜 병행(위 4절과 동일 원칙).
- 다크모드 대비 명도 확인은 실제 구현 단계에서 WCAG AA 기준 재검증 필요(이 문서의 HEX 값은 제안 단계로 미검증).

## 6. 확정 여부 안내

이 문서의 색상/서체/구체 수치는 전부 **제안**이며, 실제 브랜딩·디자인 시스템 확정 작업(로고, 아이콘 세트, 실제 목업 툴 작업 등)은 이 프로젝트의 성숙도가 올라간 뒤 별도로 진행하는 것을 제안한다. 지금 단계의 목적은 "구현 에이전트가 화면을 만들 때 방향을 잃지 않을 정도의 가이드"를 주는 것이다.
