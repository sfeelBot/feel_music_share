🔀 혼합(Mixed) 세션 — 이 앱의 가장 독특한 기능

Spotify 참여자와 YouTube 참여자가 같은 세션에 동시에 공존한다. 세션 전체가 하나의 서비스로 고정되지 않고, 참여자 개인이 각자 어떤 서비스로 참여할지를 정한다. 곡은 플랫폼 중립 식별자(제목/아티스트)로 등록되고, 참여자마다 자기 플랫폼에서 자동 매칭을 시도한 뒤 반드시 개인이 직접 확인해야 재생에 반영된다 — 절대 조용히 확정되지 않는다(09문서 결정 2, 실측 검증 완료).

⚙ 시스템 반응(의도된 설계)

다음 대기 항목이 이어서 표시되어야 한다("여러 개면 다음/이전으로 넘기는 큐 형태").

⚠ 알려진 이슈(검증 Round 7 · R7.13, 반려 권고 상태): MatchingQueueSheet의 큐 진행 로직이 React state batching을 고려하지 않은 인덱스 연산 결함을 갖고 있다 — 정확히 2건이 쌓인 흔한 경우(기본 정원 2명 데모에서 곡 2개를 연달아 추가하는 시나리오로도 재현됨) 첫 항목 처리 직후 두 번째 항목을 보여주지 못한 채 시트가 조기 종료되고, 3건 이상이면 항목이 통째로 건너뛰어진다. 정책 위반은 아니다 — 건너뛰어진 항목의 confirmState는 여전히 pending으로 안전하게 남고 재생에도 반영되지 않는다(위 5·6단계 정책은 지켜짐). 다만 "순서대로 확인한다"는 체감 흐름이 깨져 있어 다음 구현 라운드에서 수정이 필요하다.
