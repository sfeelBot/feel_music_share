  - `docs/design/03-screen-mockups.html`(폰 프레임 시각 목업)은 이번 작업 범위가 아니므로 건드리지 않음 — 혼합 모드 관련 화면(2.6c, 2.10d, 2.11a~d)의 시각 목업 반영은 리더가 필요 시 별도 요청할 것.
  - 백그라운드에서 진행 중인 구현 에이전트의 코드(`apps/`)는 건드리지 않음.
  - 커밋하지 않음 — 리더가 사용자 확인 후 처리.
