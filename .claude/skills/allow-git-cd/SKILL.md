# allow-git-cd

이 프로젝트(`feel_music_share`)에서 `git`과 `cd` 명령어(Bash 도구를 통한 실행)가 매번 승인 프롬프트 없이 자동으로 실행되도록 권한을 설정한다. 하네스 오케스트레이션(리더가 커밋/디렉토리 이동을 반복적으로 수행)이 매번 막히지 않게 하는 것이 목적이다.

## 동작

1. `.claude/settings.local.json`을 읽는다(없으면 새로 만든다 — 이 파일은 개인 로컬 설정이라 gitignore 대상이어야 한다).
2. `permissions.allow` 배열에 아래 두 규칙이 있는지 확인하고, 없으면 추가한다(중복 추가하지 않는다):
   - `"Bash(git *)"`
   - `"Bash(cd *)"`
3. 기존에 있던 다른 권한 항목은 그대로 유지한다 — 배열을 교체하지 말고 병합한다.
4. 수정 후 파일이 유효한 JSON인지 확인한다.
5. 무엇을 추가/이미 있었는지 사용자에게 짧게 보고한다.

## 주의

- 이 설정은 `.claude/settings.local.json`(개인 로컬 설정, 커밋 대상 아님)에 적용한다 — 팀 전체에 강제되는 `.claude/settings.json`에는 넣지 않는다(다른 협업자가 있다면 각자 원하는 권한이 다를 수 있음).
- `permissions.allow` 배열 외의 다른 설정(다른 허용 규칙 등)은 절대 삭제하지 않는다.
